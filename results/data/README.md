# Result data

These files are generated by `python scripts/run_all.py`:

- `summary.csv`: mean/std/max/quantiles and counts in both pre- and post-LayerNorm spaces.
- `thresholds.json`: observed gaps, unused unimodal candidates, and the frozen shared cutoff.
- `threshold_sensitivity.csv`, `original_threshold_diagnostic.csv`, `scale_adjusted_tail.csv`: absolute and relative cutoff checks.
- `layer_statistics.csv`: per-model/layer means, population std, thresholds, maxima, counts, and percentages.
- `per_image.csv`, `*_patch_norms.csv`: every final normalized-output patch norm and both feature-space norms.
- `*_attention_mass.csv`: CLS/register/patch probability mass before spatial slicing.
- `redundancy.csv`: neighboring input-embedding cosine by final outlier status.
- `background_proxy_summary.csv`, `background_proxy_per_image.csv`: counts outside/inside COCO object-mask unions.
- `image_sources.json`, `image_attribution.csv`: exact input hashes, dimensions, source URLs and licenses.
- `models.json`, `environment.json`, `run_provenance.json`, `validation.json`: pinned revisions, versions/hardware, settings/source hashes, and integrity checks.

Uncommitted NPZ arrays are regenerated for each model:

| Key | Shape / meaning |
|---|---|
| `layer_norms` | `[20, blocks+1, 1369]`, raw hidden-state patch L2 norms; stage 0 is input embedding |
| `final_norms` | `[20, 1369]`, **pre-LayerNorm** final-block norms |
| `normalized_norms` | `[20, 1369]`, **post-LayerNorm** `last_hidden_state` norms (primary result) |
| `embedding_neighbor_cosine` | `[20, 37, 37]`, mean cosine to available 2–4 neighbors |
| `selected_indices` | six source-image indices, in manifest order |
| `features` | `[6, 1369, hidden_size]`, final **normalized** patch features |
| `pca_rgb`, `pca_variance_ratio` | per-image/model PCA previews and explained variance ratios |
| `cls_attention` | `[6, 37, 37]`, mean-head final CLS-to-patch probabilities |
| `cosine` | `[6, 37, 37]`, FeatLens similarity to the center patch |
| `rollout`, `rollout_mass` | raw CLS rollout probabilities and CLS/register/patch mass |

`background_proxy_masks.npz` records patch centers outside every annotated object/crowd mask.

The code is MIT licensed. Photographs and image-containing figures retain their original terms; see `../../images/SOURCES.md`.

`fresh_environment_validation.json` is the repository-preparation audit: it records the successful independent CLI and notebook runs, exact installed packages, and comparison tolerances/errors against the original experiment. It is separate from the per-run scientific outputs above.
